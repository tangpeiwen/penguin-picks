# 饭局餐厅推荐小程序

一个根据吃饭场合、人数和区域，从私人餐厅清单中直接推荐 3–4 家餐厅的微信原生小程序 Demo。

## 当前能力

- 八个场合按钮：约会、请客、朋友聚会、带爸妈、过生日、安静谈事、一人食、随便吃点；另保留“看看我都吃了什么”浏览入口
- 人数与上海常用片区的多选：不限区域、静安寺、南京西路、新天地、淮海中路、衡山复兴、徐家汇、愚园路、古北、虹桥虹梅、外滩、苏河湾、陆家嘴、前滩、三林上南、西岸、虹口北外滩、其他区域
- 基于场合、容纳人数、区域、评价完整度和星级的本地推荐评分
- 菜系、人均、忌口收窄，以及换一批
- 结果卡展示短评、人均、区域、菜系与订位难度
- 一套酒红与白色双版本的透明手绘 PNG 图标
- 乐米小奶泡体的页面文字子集，标题与按钮使用手写字体，正文保持系统字体
- 87 家带评价和经纬度的真实餐厅数据，无需后端即可演示
- 点击餐厅生成点菜卡：只使用 CSV 已录入的菜名，按人数最多取 3 / 4 / 6 / 7 项、不补齐，并显示完整评价、有内容的避雷、异常订位提示和地址，可生成干净图片保存
- 结果页提供统一的列表 / 地图切换，并可直接调用微信地图导航

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择“导入项目”。
2. 目录选择本仓库根目录。
3. 导入界面选择“测试号”即可本地体验；准备发布时，再填写你自己的正式小程序 AppID。
4. 编译后从首屏完成三次点击，即可查看推荐。

## 更新餐厅数据

源数据是 `outputs/大众点评_合并_带经纬度.csv`。更新 CSV 后执行：

```bash
python3 tools/build_miniprogram_data.py
```

脚本只将“评价”不为空的行写入 `miniprogram/data/restaurants.js`。

图标位于 `miniprogram/assets/icons`。如需从透明图标母版重新裁切，可执行：

```bash
python3 tools/split_icon_atlas.py
```

## 更新手写字体

小程序使用 `miniprogram/styles/fonts.wxss` 导入的两个内嵌 WOFF2 字体分片，避免把完整中文字体放进代码包，并保证每个资源小于 200 KiB。页面文案或餐厅名称、菜系增加新字后，执行：

```bash
/usr/bin/python3 tools/build_font_asset.py "/path/to/乐米小奶泡体.ttf"
```

脚本需要本机提供 `pyftsubset`。它只为静态界面文案、餐厅名和菜系生成字体；评价、地址、菜品等系统正文不会进入手写字体子集。

## 数据说明

忌口筛选目前依据菜系和已有评价做初筛，不能替代餐厅提供的过敏原信息。正式发布前，建议为每家餐厅补充经过确认的忌口与过敏原字段。
